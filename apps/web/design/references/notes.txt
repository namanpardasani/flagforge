FlagForge design references
===========================

The images in this folder are MOOD and LAYOUT references only. Nothing is copied from them.
They are screenshots of other companies' products, so they are git-ignored and stay on this
machine. Only this file is committed.

No notes file was supplied with the references; the written direction in "Prompt 1" is the brief.
This file records that direction and what each image contributed.

Direction: "Control room blueprint"
-----------------------------------
Dark, technical, handmade. Must not look AI-generated.
Colours: bg #0C0C0B, raised #141412, hairline #26241F, text #E8E4DC, muted #8A867D,
         ember #FF5A1F (ONLY live / on / active), danger #E5484D.
Fonts:   Geist Sans (UI), Geist Mono (keys, numbers, captions),
         Instrument Serif italic (one accent word per headline).
Shape:   2-4px radius, hairline borders, crosshair marks at card corners, subtle static film
         grain, mono captions like "FIG 0.1", faint background grid on marketing surfaces.
Banned:  purple/blue gradients, glassmorphism, gradient icon squares, three identical centred
         cards, emoji, lorem ipsum, filler stats, default shadcn look,
         "Supercharge / Unlock / Seamless" copy.
